ODISHA SATHI - LOCKED HOMEPAGE LAYOUT

This package changes only app/page.tsx.

Included layout:
- Latest Jobs: up to 18 posts in one long panel.
- Latest Admit Cards & Exams: up to 6 posts.
- Latest Results: up to 6 posts.
- Latest Admissions: up to 6 posts.
- The three secondary panels are stacked beside Latest Jobs on desktop.
- All Important Information and Latest Schemes start together in a matched bottom row.
- Both bottom sections have independent View More controls in batches of 10.
- Tablet and mobile use a clean single-column layout.

INSTALL
1. Copy app/page.tsx into the project and replace the existing file.
2. Run npm run build.
3. Test the homepage locally on desktop and mobile.
4. Commit and push only after approving the layout.

ROLLBACK
Use the separate odisha-sathi-homepage-layout-rollback.zip package. It restores
only the previous app/page.tsx and does not affect indexing or other features.
